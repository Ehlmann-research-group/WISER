WISER Documentation#

WISER — the Workbench for Imaging Spectroscopy Exploration and Research — is an open-source, cross-platform application for visualizing and analyzing hyperspectral imagery. It is written in Python on Qt/PySide, runs on macOS, Windows and Linux, and needs no commercial license.

Developed and maintained by the Ehlmann Research Group at Caltech and CU Boulder. Questions: wiser_AT_lists.lasp.colorado.edu.

What WISER does#

Look at data

  • Load, display and navigate hyperspectral and multispectral rasters

  • Context, main and zoom panes that stay in step, plus a grid view for comparing datasets side by side

  • Contrast stretches, conditioners, colormaps and a decorrelation stretch

Read spectra

  • Click any pixel for its spectrum; collect, color, average and export them

  • Import ENVI spectral libraries and ASCII spectra

  • Continuum removal on a spectrum, a collection, or a whole cube

Compute

  • Band math with a full expression language, saved expressions and batch processing over a folder

  • Regions of Interest for class signatures, masks and pixel exports

  • Savitzky–Golay, mean, median and Gaussian filters

Analyze

  • Transforms — Principal Component Analysis, Minimum Noise Fraction

  • Classification — K-means clustering

  • Detection — Spectral Angle Mapper, Spectral Feature Fitting, Mixture-Tuned Matched Filter

  • Unmixing — Linear Unmixing with per-pixel residuals

  • Visualization — Interactive Scatter Plot linked back to the image

Handle geometry

  • Georeferencing from ground control points, custom coordinate reference systems, similarity transforms

  • Mosaicking overlapping scenes onto one output grid

Keep and share your work

  • Projects that save the whole session to a single file, referenced or self-contained

  • A plugin API for adding your own analyses without rebuilding

System Requirements#

The minimum and recommended specifications for running WISER are:

Operating system

  • Windows: Windows 10 or 11 (64-bit)

  • macOS: macOS 15 or newer (Intel and Apple Silicon)

  • Linux: Ubuntu 20.04+, Debian 12+, or Fedora 39+ (amd64 and aarch64)

Hardware

  • CPU architecture: x86_64 (Intel/AMD) or arm64 (Apple Silicon / aarch64)

  • Memory: 8 GB minimum; 16–32 GB recommended for large datasets

  • Storage: ~1 GB for installation; SSD strongly recommended

  • GPU: Not required

If you encounter issues building or running WISER, please open a GitHub Issue.

Data to try#

The Tutorials run on fixtures in the WISER source tree, so there is nothing to download. For full scenes, try these public datasets:

  • AVIRIS-NG Caltech subset (plus its header) — 425 bands over Pasadena

  • AVIRIS-Classic reflectance over Cuprite, Nevada (plus its header) — 224 bands

  • AVIRIS Data Portal and AVIRIS free data — more airborne scenes

  • EMIT L2A Reflectance — spaceborne imaging spectroscopy of arid land surfaces

  • PACE/OCI — hyperspectral ocean color

  • CRISM MTRDR over Jezero Crater — 489 bands

  • PDS Geosciences Node and the Mars Orbital Data Explorer — CRISM, OMEGA, M3 and more

  • Ehlmann Lab datasets — laboratory and field imaging spectroscopy

  • USGS Spectral Library Version 7 and the ECOSTRESS Spectral Library — reference spectra
