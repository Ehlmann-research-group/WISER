User Manual#

This manual covers the WISER graphical interface: how to load and display data, explore spectra, work with Regions of Interest (ROIs), run analysis tools, and manage spatial reference systems.

Start with Interface Overview to orient yourself, then work through Working with Data for the core data exploration workflow.

Tutorial Exercises#

The following step-by-step tutorials are a great way to get up and running quickly:

  • Beginner Tutorial — A guided walkthrough of loading data and exploring WISER’s core features.

  • Advanced Tutorial — Covers plugins, spectral analysis workflows, and advanced tooling.

What’s in This Manual#

  • Interface Overview — tour of the main window, toolbars, spectral plot, and display controls

  • Working with Data — loading files, navigating bands, ROIs, analysis tools, and exporting results

  • Data Analysis Tools — transforming, classifying, detecting, unmixing, and visualizing imagery

  • Spatial Tools — georeferencing and coordinate system management
