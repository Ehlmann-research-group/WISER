Getting started
===============

This page hosts the documentation for how to get started using WISER from source and
contributing to WISER. There will be information how environment setup, WISER's CI/CD 
pipelines, PR best practices, and documentation on the code.

Prerequisites
-------------

WISER builds currently target MacOS 15 (both ARM and Intel), Windows 10/11, and Ubuntu 20.04+,
Debian 11+, and Fedora 39+ for amd64 and aarch64 CPU architectures.

Building from source on these platforms should work when following the `devenv` guides for that
platform. If it does not work, please create an issue or discussion post.
