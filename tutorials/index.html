Tutorials#

There are eight short tutorials, a little over two hours end to end. They run on data that ships with the WISER source, so there is nothing to download. Work through them in order and you will have used every major tool in the application on a real scene. If WISER is not installed yet, start with Installation.

What you are working with

A GIS layer stores one value per pixel, or three if it is a color image. The scenes here store up to several hundred. Every pixel holds a spectrum: a measurement of how much light that patch of ground reflected at each of 4, 15 or 425 wavelengths. WISER is built to read those spectra.

So instead of arranging layers to make a picture, you read a measurement out of any pixel you click (Tutorial 2), average it over an area to get a signature you can trust (Tutorial 3), compare it against a laboratory reference to identify what is on the ground (Tutorial 7), and let the shapes of those spectra sort the scene into classes on their own (Tutorial 5).

Keep the Spectrum Plot pane open throughout. Most of what makes a result believable is visible there and nowhere else.

The data#

Everything these tutorials need is already in your WISER checkout:

src/test_utils/test_datasets/     rasters
src/test_utils/test_spectra/      spectral libraries

These are the project’s unit-test fixtures, so they are small on purpose — a 150 × 150 pixel campus scene, a 7 × 7 pixel 425-band cube, a 20 × 22 pixel short-wave infrared subset with a bad-band list. They are real data, and they are enough to exercise every tool.

If you installed WISER from a release rather than from source, get them by cloning the repository:

git clone https://github.com/Ehlmann-research-group/WISER.git

Without git, open the repository page on GitHub and choose Code ▸ Download ZIP.

Every screenshot in the tutorials was taken from WISER by a script that runs the steps described, not mocked up.
